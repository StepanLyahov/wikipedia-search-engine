# Wikipedia Search Engine

## Описание проекта

В течение курса вы будете разрабатывать небольшую полнотекстовую поисковую систему по статьям Википедии.

К концу курса система будет состоять из следующих сервисов:

* `crawler` — скачивает страницы Википедии (Golang);
* `indexer` — извлекает текст из HTML и индексирует документы (Golang);
* `embedding-service` — генерирует embeddings (Python);
* `search-api` — предоставляет REST API для поиска (Golang);
* `postgresql` — хранит скачанные страницы;
* `elasticsearch` — хранит поисковый индекс.

# Архитектурные ограничения

В рамках курса используются следующие правила.

## 1. Каждый сервис запускается отдельно

Каждый компонент является отдельным приложением.

Каждый сервис имеет:

* собственный Dockerfile;
* собственный main.go;
* собственную конфигурацию.

---

## 2. PostgreSQL является источником истины

Скачанные страницы должны храниться только в PostgreSQL.

Запрещается:

* хранить HTML в Elasticsearch;
* повторно скачивать страницы из Википедии.

---

## 3. Elasticsearch используется только для поиска

Elasticsearch хранит:

* title;
* body;
* url;
* embedding.

---

## 4. Embeddings генерируются отдельным сервисом

Сервис `indexer` не должен знать:

* как устроена ML модель;
* какая библиотека используется;
* где выполняется inference.

`indexer` получает embedding через gRPC.
